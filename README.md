# github-boiler

A clean, reusable GitHub repository foundation for new projects.

## Included

- Community health files
- CI and dependency review workflows
- Issue and pull request templates
- Standard repository metadata and editor defaults

## Quick Start

1. Update project name and description.
2. Review and customize templates in `.github/`.
3. Add project code in `src/` and tests in `tests/`.
4. Enable branch protection and required checks in GitHub settings.

## Repository Layout

- `src/` application or library code
- `tests/` automated tests
- `docs/` project documentation
- `scripts/` helper scripts
- `.github/` workflows and templates
